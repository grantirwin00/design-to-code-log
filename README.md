# Design to Code Diary

A personal design log documenting decisions, iterations, and lessons learned across projects.

## About

Built with [Jekyll](https://jekyllrb.com/) and hosted on [GitHub Pages](https://pages.github.com/).
Each post captures the reasoning behind design work -- what was tried, what failed, and what shipped.

Live site: [grantirwin00.github.io/design-to-code-log](https://grantirwin00.github.io/design-to-code-log/)

## Structure

- `index.md` -- home page and entry index
- `_posts/` -- individual log entries, named `YYYY-MM-DD-title.md`
- `_config.yml` -- Jekyll configuration
- `assets/css/style.scss` -- custom stylesheet
